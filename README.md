# Shinobi Survivors

An original browser-based 3D action roguelite about the arts of Flux, Resonance and the broken Veil.

## Project status

Early development. The playable vertical slice is being built in a separate feature branch.

## Creative direction

Shinobi Survivors is an original game universe. No third-party anime characters, logos, names, music, or assets are used. All code, visual elements and story concepts in this repository should be independently created or appropriately licensed.

## Development

The game uses TypeScript, Vite, React and Three.js. Setup and commands will be added with the first playable implementation.
